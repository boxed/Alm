-- TYPE MISMATCH -------------------------------------------------- src/Main.elm

The 1st argument to `needs` is not what I expect:

11|     needs { x = 1 }
              ^^^^^^^^^
This argument is a record of type:

    { x : number }

But `needs` needs the 1st argument to be:

    { x : Int, y : Int, z : Int }

Hint: Looks like fields y and z are missing.
