-- TYPE MISMATCH -------------------------------------------------- src/Main.elm

I cannot update the `x` field like this:

11|     { point | x = "one" }
                      ^^^^^
You are trying to update `x` to be a string of type:

    String

But it should be:

    Int

Note: The record update syntax does not allow you to change the type of fields.
You can achieve that with record constructors or the record literal syntax.

Hint: Want to convert a String into an Int? Use the String.toInt function!
